# # Wildlife Camera Trap Analysis

## Aim

To analyze wildlife camera-trap observations and identify patterns based on **species, location, and time of sighting**.

## Data Processing

* Removed missing and duplicate records.
* Removed blank trigger records.
* Converted sighting time into proper datetime format.
* Extracted the hour from the sighting time.
* Classified sightings as **Diurnal** and **Nocturnal**.

## Visualizations

The Power BI dashboard contains:

* Species-wise Sighting Frequency – **Bar Chart**
* Location-wise Sighting Frequency – **Bar Chart**
* Species vs Location – **Heatmap**
* Diurnal vs Nocturnal Activity – **Pie Chart**
* Wildlife Activity by Hour – **Line Chart**
* Species-wise Diurnal and Nocturnal Activity – **Bar Chart**

## Insights

* Identified the most frequently sighted species.
* Identified the location with the highest wildlife activity.
* Compared diurnal and nocturnal wildlife activity.
* Identified the peak hours of wildlife activity.
* Compared species activity across different locations.
